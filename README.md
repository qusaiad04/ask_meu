Ask MEU - Campus Assistant App
A centralized mobile hub designed to streamline the student experience at Middle East University.

🌐 Live Demo
👉 Click here to launch Ask MEU in your browser

🛠 Tech Stack
🚀 Features
Academic Advising: Quick access to essential academic guidance and curriculum information.

Campus Navigation: Tools to help students find their way around campus facilities.

Facility Reporting: A streamlined system for students to report issues directly to the administration.

Smart Assistance: Integrated Gemini API to provide instant, AI-driven responses to student inquiries.

User-Centric Design: Clean, responsive UI built with Flutter, focused on accessibility and ease of use.

💡 Key Learnings
During the development of Ask MEU, I focused on:

Implementing Clean Architecture in Flutter for maintainable code.

Integrating external APIs (Gemini) to provide smart, real-time responses.

Managing state efficiently using modern Flutter patterns for smooth navigation and performance.

Ensuring UI/UX consistency across different mobile screen sizes using Figma prototypes.
